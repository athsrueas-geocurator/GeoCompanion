# USA Minimum Seed Dataset

This folder contains a minimal, push-friendly USA-specific seed copied from the Open_Data educational inequality pipeline.

## Included files
- `jurisdictions.csv`: USA jurisdiction row only.
- `observations.csv`: USA-only country-year observations from World Bank phase-1 export.
- `metrics.csv`: phase-1 metric definitions required to interpret observations.
- `datasets.csv`: dataset identifier metadata.
- `dataset_releases.csv`: release metadata for the snapshot.
- `indicator_definitions.csv`: source indicator metadata for metrics.
- `boundaries/USA.geojson`: geoBoundaries ADM0 simplified polygon for the USA.
- `source_records.csv`: minimum source registry records for this seed.

## Provenance
Copied from `Open_Data` on 2026-05-13 with source snapshot dates preserved from the original manifests.
