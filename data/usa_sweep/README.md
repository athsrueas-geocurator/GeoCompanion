# USA Sweep Package

Automated extraction of USA-specific records and USA-relevant source records from Open_Data.

## Folders
- `records/`: USA-focused data rows extracted from CSV datasets.
- `sources/`: Source registry/manifests and USA-relevant source rows.
- `inventory/`: Index files showing what was found and copied.

See `inventory/usa_sweep_inventory.csv` and `inventory/summary.json`.
